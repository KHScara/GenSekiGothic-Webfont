# GenSekiGothic-Webfont
本專案為源石黑體（GenSeki Gothic）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

原作者：ButTaiwan（But Ko）
```
@font-face {
  font-family: "GenSekiGothic";
  font-display: swap;
  font-style: normal;
  font-weight: 300;
  src: url("https://cdn.jsdelivr.net/gh/KHScara/GenSekiGothic-Webfont@main/GenSekiGothic2TC-L.woff2") format("woff2");
}

@font-face {
  font-family: "GenSekiGothic";
  font-display: swap;
  font-style: normal;
  font-weight: 400;
  src: url("https://cdn.jsdelivr.net/gh/KHScara/GenSekiGothic-Webfont@main/GenSekiGothic2TC-R.woff2") format("woff2");
}

}
